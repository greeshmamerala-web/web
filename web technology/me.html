Structure of html

  • Head includes title tag and meta tags.
  • meta tags are used to access the meta data.
  • Body includes the webpage content including many tags and elements.
Attribute
  • HTML tags define the structure and meaning of content,while attributes provides extra information or modify the behaviour of those elements.
  • Attributes are always specified in the start tag and usually follow the[name="value"]format.
  • For example:class,style,src,alt,lang.......
  • Attribute always depends on the tags but tags doesn't depends on the attribute.
Heading tags
  • We can include headings by using header tags.
  • Heading tags are of 6 types.They are from h1 to h6.
  • h1 has the maximum size and h6 has the minimum size.
Paragraph tag

We can include paragraph by using paragraph tags through opening the tag 'p' and entering the content in it and should close the paragraph tag.

Image tag
  • We can add images by using image tag.
  • Image tag has source attribute,alternative attribute,helight attribute and width attribute.
  • Source attribute specifies the location/path of the image.
  • Alternative attribute provides the alternative text to the image.
  • Height and width tells the size of the image.
Anchor tag/Hyper links
  • Anchor tag/Hyper linknis used to link any two or more webpages
  • Anchor tag has two attributes in it,they are href and target.
  • Href means hyperreference which includes the file which we are linking with this file.
  • Target tell that whether the linked webpage is displayed on the same tab or in a new tab. If we use target='_self' ,the linked webpage is displayed on the same tab and if we use target='_blank' then the linked webpage will be displayed on another new tab.

Tag Element

Eg:p,h1,h2,h3,h4,h5,h6,..... Eg:opening tag+content+closing tag=Element

Text formatting tags

Text formatting tags are of 8 types,they are:

  • Bold text
  • Strong text
  • Italic text
  • Emphasized text
  • Small text
  • Mark text
  • Deleted text
  • Inserted text
  1. Bold text:It mainly draws attention to text visually,it does not indicate that the text has strong importance.
    Eg:Bold
  2. Strong text:It indicates that the text has strong importance.
    Eg:Warning,Caution,Precaution.....
  3. Italic text:It displays text in italic style.It can be used for things such as:Technical terms,Foreign words,thoughts,names of certain works....
    Eg:Foreigners
  4. Emphasized text:It represents emphasis(special importance)
    Eg:Danger
  5. Small text:It displays the text in a smaller font size.
    Eg:Listen!
  6. Mark text:It highlights the text.The basic colour of the highlighter is yellow.
    Eg:Shutup your mouth
  7. Deleted text:It represents text that has been deleted.Browsers normally displays it with a line thtrough the text.
    Eg:pythoon
  8. Inserted text:It represents text that has been inserted or added.Browsers commonly display it with an underline.
    This is particularly useful for showing changes.
    Eg:pythoonpython
